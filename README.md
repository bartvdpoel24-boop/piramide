# Piramide

Ladder voor potjes pool. Je daagt iemand uit die maximaal vier plaatsen boven je staat. Win je, dan wissel je van briefje. Houdt de nummer 1 stand, dan een stip.

- Demo zonder account, op dit apparaat
- Echte ladder via Google, met uitnodigingscode
- Beschikbaarheid per dag, uitdagingen en uitslagen
